# 📊 Web Scraping Project – Book Data

## 🔹 Overview
This project demonstrates web scraping using Python. Data was extracted from a public website and converted into a structured dataset for analysis.

## 🔹 Tools & Libraries
- Python
- BeautifulSoup
- Pandas
- Requests

## 🔹 Features
- Extracted book titles, prices, and availability
- Cleaned price data into numeric format
- Stored data in CSV file

## 🔹 Dataset
The dataset includes:
- Title
- Price (£)
- Availability
